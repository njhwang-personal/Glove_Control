# Glove-Controlled Drone

## Overview
This project implements a wearable glove controller for drone control using a custom PCB, wireless communication, and a simulated drone environment.

## Repository Contents
- `glove_ctrl.py` – Webots controller code
- `glove_main.c` – STM32 firmware (STM32CubeIDE)
- `pi_receiver_final.c` – Raspberry Pi RF receiver and UDP bridge
- `Glove_32pin.kicad*` – KiCad schematic and PCB layout files for the glove controller
